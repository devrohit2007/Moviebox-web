MovieBox Web — premium UI + performance update

1. Back up your current project folder first.
2. Extract this ZIP into a NEW folder (recommended), keeping the included static/ folder.
3. Install the project's existing requirements, including Flask and requests, in your Python environment.
4. Run: python server.py 8000
5. Open http://127.0.0.1:8000 on the server device, or the LAN URL printed in the terminal on other devices connected to the same Wi-Fi.

The server expects static/index.html; this ZIP includes it in the correct location.
Keep your existing requirements file and any other project assets (icons, etc.) when merging. This ZIP does not include provider credentials or unrelated files.

Performance improvements include short-lived in-memory API caching, duplicate-request coalescing, pooled upstream connections for proxy/subtitle traffic, and subtitle caching. Cache is in-memory and resets when the server restarts. Actual playback speed still depends on the upstream source, Wi-Fi/router, and server device.
